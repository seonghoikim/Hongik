## 2. 논문 해석에 영향을 주는 문제

### 2.1 v_final 불일치 (중요)

- **현상:** `self_healing_loop`는 마지막 라운드(라운드 상한)에서도 실패 사례로 Meta-Rule을 만들고 `next_version`으로 버전을 올린 뒤, 그 버전을 v_final로 반환한다. 이 버전은 치유용 셋에서 한 번도 평가되지 않았다.
- **실측 확인:** 라운드 상한에 걸려 끝난 실행 전부에서 헬드아웃·적응형 재공격·교차 모델 검증이 "마지막 평가 버전 + 1"로 실행됐다.

| 실행 | 마지막 치유 라운드 | 헬드아웃·적응형·교차 모델 |
|---|---|---|
| 7차 | v1.4 | v1.5 |
| 8차 | v1.4 | v1.5 |
| 9차 (수렴) | v1.13 | v1.13 (일치) |
| 10차 / 11차 | v1.14 / v2.14 | v1.15 / v2.15 |
| 12차 | v1.2 | v1.3 |

- **논문 영향:** 논문 표 6·8은 round_5를 "v1.4 (v_final)", 헬드아웃을 "v_final"로 적었으나 실제 헬드아웃은 v1.5다(표 10은 8차를 v1.5로 바르게 적음). "헬드아웃 준수율이 치유용 최종 라운드와 통계적으로 구분되지 않는다(Mann-Whitney, 7차 p=0.773)"는 서로 다른 SRS 버전(v1.4와 v1.5)을 비교한 것이다. 9차의 결론은 영향이 없다.
- **선택지:** (a) 논문 정정 — 재실행 없이 v_final을 실제 버전(v1.5)으로 고치고, 7·8차의 일반화 비교에 "버전이 한 단계 다르다"는 단서를 붙인다. (b) 코드 수정 — 상한 도달 시 마지막 Meta-Rule 생성을 생략하거나, 마지막으로 평가된 버전을 v_final로 쓴다. 이후 실행부터 적용된다.

### 2.2 교차 모델 검증의 통계 검정 선택

- **현상:** 교차 모델 검증은 같은 헬드아웃 문항을 3개 모델이 각각 응답한 반복측정(대응) 자료인데, 독립 집단을 가정하는 Kruskal-Wallis와 카이제곱 독립성 검정을 쓴다.
- **논문 영향:** 표 7(요약본 기준)의 p값 0.829, 0.031, 0.230이 이 검정에서 나왔다. 특히 "8차에서만 벤더 차이가 유의"라는 해석은 검정을 바꾸면 달라질 수 있다.
- **선택지:** 점수는 Friedman 검정, PASS 여부는 Cochran's Q 검정으로 다시 계산한다. 결과 JSON에 문항별 백엔드 점수가 있어 API 비용 없이 재계산할 수 있다.

### 2.3 준수율 지표의 하한

- **현상:** 준수율 = 총점 / 만점이라 전원이 최하 등급이어도 0%가 아니다(3단계 33.3%, 현재 코드의 4단계 25.0%).
- **논문 영향:** "68.2% → 100%" 같은 수치의 실제 개선 폭이 겉보기보다 작다. 키트 규칙(R9: 수치는 기준선과 함께)에 따라 하한이나 등급 분포를 함께 보고하는 것이 안전하다.

## 4. 참고 사항

- **유닛 A 차단과 교차 모델 검증:** 유닛 A가 입력을 차단하면 3개 백엔드가 같은 고정 문구를 받아 "검증됨"으로 집계될 수 있는 구조다. 실측 영향은 없다(7~9차 헬드아웃에서 유닛 A 차단 0건).
- **실명 노출:** 논문은 대상 기업을 "가전 유통 고객사"로 익명화했으나, `srs.py`의 초기 SRS와 결과 JSON에는 실제 업체명과 서비스명이 그대로 있다. 저장소 공개 범위를 확인해야 한다.
- **유닛 B:** 코드의 RAG는 소형 키워드 매칭 지식베이스다. 요약본 3.2절의 "외부 데이터 유입을 물리적으로 격리" 표현은 이 구현 수준에 맞게 조정하는 것이 정확하다.

### 재계산 결과 (교차 모델 3개 백엔드)

| 실행 | SRS | n | 최상위 등급률 (openai / gemini / anthropic) | Friedman p | Cochran's Q p | 기존 Kruskal-Wallis p |

| 8차 | v1.5 | 22 | 68.2 / 50.0 / 31.8 | 0.036 | 0.059 | 0.031 |

해석이 바뀌는 곳은 8차 하나다. 점수 기준(Friedman)으로는 여전히 유의하지만 PASS 여부 기준(Cochran's Q)으로는 유의하지 않아, "8차에서 벤더 차이가 유의"는 "점수 기준으로만 유의, 경계 수준"으로 고쳤다. 나머지 실행은 유의 여부가 그대로다. 2/3 검증 비율은 검정과 무관하므로 바뀌지 않는다.
