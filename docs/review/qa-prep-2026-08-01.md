# 지도교수 미팅 예상 질문 Q&A (2026-08-01)

우선순위: 교수님이 논문을 처음 보고 가장 먼저 짚을 만한 순서대로 정리.

## Q1. "이 실험 수치, 실제로 코드 돌려서 나온 거예요?"
**예상 강도: 최상 — 가장 먼저 나올 질문**

- **정직하게 답할 것**: 현재는 메커니즘 설계와 예시 시나리오 기반의 초안 수치이며, 실제 파이프라인 구현 및 재현 실험은 진행 중이라고 말씀드리는 것을 권장합니다.
- 이미 실제 결과인 것처럼 발표하면 나중에 재현이 안 될 때 훨씬 더 큰 문제가 됩니다. "다음 스프린트에 4개 유닛(A~D)과 무상태 평가 파이프라인을 코드로 구현해 동일 실험을 재현할 계획"이라고 답하면 됩니다.
- 후속 조치: 지금부터 실제 코드 구현에 들어가서, 다음 미팅 전까지 최소 1회 실제 실행 결과를 확보하는 것이 목표.

## Q2. "50개로 고치고 같은 50개로 다시 채점했으면 100%는 당연한 거 아닌가요?"
**예상 강도: 최상**

- 맞는 지적임을 인정하고, **held-out(미공개) 테스트셋**을 별도로 구성해 최종 검증 단계에서 사용하겠다고 답변.
- 구체적 설계: 치유용 50개(training set) + 검증용 30~50개(held-out set, 치유 과정에서 전혀 노출되지 않은 신규 공격 시나리오). held-out 셋에서도 높은 방어율이 나와야 "일반화"를 주장할 수 있음.

## Q3. "SRS를 자동으로 보강한다고 했는데, 그 분석과 규칙 작성을 사람이 하나요, LLM이 하나요?"
**예상 강도: 상**

- 지금 초안 상 모호함. 답변 전 반드시 스스로 정의를 확정해야 함:
  - (A) 완전 자동: 실패 로그를 LLM에 입력 → LLM이 Meta-Rule 문구를 직접 생성 → 자동 삽입.
  - (B) 반자동: 사람이 실패 패턴을 분석하고 결정하되, 삽입/재실행은 자동화.
- **권장**: (A)를 목표로 실제 구현하고, 안 되면 논문에서 "Self-Healing"이라는 표현 대신 "Guided Specification Hardening" 등으로 정정. 과장된 용어는 심사에서 바로 지적받음.

## Q4. "심판관 LLM(Judge)이 채점을 정확히 하는지는 어떻게 검증했나요?"
**예상 강도: 상**

- 현재 검증 없음. 최소한의 대응: 50개 중 10~15개를 사람이 직접 채점해서 LLM 심판관 점수와 일치율(agreement rate)을 계산한 예비 결과를 준비.
- "Cohen's Kappa" 같은 합치도 지표까지는 무리여도, 최소 "사람-LLM 채점 일치율 X%"는 다음 미팅 전 준비 권장.

## Q5. "왜 하필 가전 유통(하이마트)이에요? 제목은 '다양한 고객 조직'인데 사례가 하나뿐인데요?"
**예상 강도: 중상**

- 답변: 1차로 가전 유통을 파일럿으로 검증했고, 향후 금융/의료 등 이질적 도메인으로 확장 예정(6장 한계점에 이미 명시됨을 강조). 다만 제목이 과대주장이라는 지적은 타당하므로, 최소 2번째 도메인(예: 금융 상담봇) 실험을 하나 더 추가하는 것을 권장.
- 실명(하이마트) 노출은 익명화("A사")로 먼저 수정.

## Q6. "참고문헌 저자 확인은 했어요?"
**예상 강도: 중 (이미 선제 대응 완료)**

- 이미 검증 완료 및 수정본 있음 (`draft-review-2026-08-01.md` 참고). "직접 arXiv 원문 대조해서 저자명 오류 3건, 학회명 오류 1건 수정했습니다"라고 먼저 말씀드리면 오히려 플러스 포인트.

## Q7. "통계적으로 유의미한 겁니까? 한 번 돌린 결과인가요?"
**예상 강도: 중**

- 현재 단일 실행(single run). LLM 응답의 비결정성을 고려하면 반복 실행(예: 각 시나리오당 3~5회) 후 평균/표준편차를 보고해야 함.
- 답변: "다음 실험 설계에 반복 시행과 표준편차를 포함하겠다."

## Q8. "왜 파인튜닝보다 이 방법이 낫다고 할 수 있나요? 비교 실험 있어요?"
**예상 강도: 중**

- 현재 파인튜닝과의 직접 비교 실험 없음(주장만 있음). 최소 baseline 비교(예: 단순 시스템 프롬프트만 사용한 경우 vs 본 메커니즘)를 실험에 추가할 계획이라고 답변.
