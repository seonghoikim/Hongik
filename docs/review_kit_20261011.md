## 2. 구조 (R1, structure.md)

교수님 박사논문 6단계와 현재 장 구성을 대조했다.

| 6단계 | 현재 대응 | 상태 |
|---|---|---|
| 1. 기본 단위 정의 | 공격 시나리오, Meta-Rule, Action Matrix 등급이 흩어져 있음 | 정의 장이 없음 |
| 2. 배치 매트릭스 | Action Matrix (심각도 × 위반 유닛 A~D) | 개념은 있으나 매트릭스 그림·표가 없음 |
| 3. 변환 알고리즘 | 알고리즘 1 (SRS 자가 치유) | 있음. 단, 키트는 `Algorithm 1.` 번호를 쓰지 않는다 |
| 4. 사례 적용 | 가전 유통 사례, 7~13차 파일럿 | 있음 |
| 5. 메트릭과 우선순위 | 준수율, 4단계 Level | 우선순위 개념 없음 |
| 6. 재사용성 | — | 없음 (Meta-Rule의 타 도메인 재사용은 미실시) |

- 학위논문 장 구성 표준(I 서론 → II 관련연구 → III 문제 정의 → IV 핵심 방법론 → V 메트릭 → VI 통합·확장 → VII 결론)과 비교하면 "III 문제 정의(gap)" 장이 따로 없다. 현재는 서론 1.2절에 들어 있다.
- 구조 변경은 교수님 승인 사항이다(R1). 본 검수는 대응표만 제시하고 장 구성은 바꾸지 않았다.

## 5. 그림 (kim-paper-figures)

- 요약본 v2의 그림 17개를 코드로 다시 만들었다 (`diagrams/summary_v2/make_figs_v2.py`). 도식은 검정·빨강 하나·회색 두 단계, 플롯은 Okabe-Ito 팔레트, 캡션은 제목만이며 마침표로 끝난다.
- 인쇄 기준: 본문 폭 437pt에서 픽셀 폭 1,821px 이상, 최소 글자 8pt 이상 — 13개 그림 모두 `check_figure_print.py` 통과.
- 남은 문제: 그림 13~17은 2.1절 그림을 다시 실은 것이다. 같은 그림을 두 번 싣는 것은 "중복은 하나로 합친다"는 키트 원칙(figure-style §3.9)과 맞지 않는다. 5.2절의 대응 설명은 본문 문장만으로 두고 그림은 2.1절을 가리키는 방식을 권장한다.
- 용어(R14): '정보 불일치성(Information Disorderness)'은 새로 만든 용어이므로 사전 대조와 교수님 확정 절차가 필요하다.
