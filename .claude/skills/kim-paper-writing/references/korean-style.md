# 국문 문체 (번역체 금지, 학술 한국어, 표기)

## 1. 원칙

한글 논문은 영어 문장을 직역한 듯 읽히면 신뢰도가 떨어진다. 교수님 검토 문서는 문체가 곧 신뢰도다. 원칙은 다음과 같다.
- 한글에 맞게 쓰고, 용어만 영어로 둔다. 용어는 첫 등장에 영어 병기.
- 영어 동사를 옮긴 비유적 동사를 쓰지 않는다. 아래 대체표를 따른다.
- 질문형 문장, 은유, 의인화, 구어체를 본문에서 쓰지 않는다.

Why: 저자 지시(2026-09, 2026-10)로 "모두 덮었고, 사람의 몫이다, 낳는다, 세운다 같은 표현은 번역체"라는 점이 여러 차례 확인되었다.

## 2. 번역체 대체표

| 쓰지 말 것 (번역체) | 원래 뜻 (영어) | 바꿀 표현 |
|---|---|---|
| 덮다, 덮었다 | cover | 포함하다, 모두 실행하다 |
| ~의 몫이다 | is left to | ~가 수행한다, ~가 맡는다 |
| 낳다 | yield | 얻다, 만든다, 산출한다 |
| 세우다 | establish, prioritize | 정한다, 먼저 실행한다, 설정한다 |
| 메우다 | fill the gap | 해결한다, 보완한다 |
| 갭 | gap | 문제, 한계, 공백 |
| 맺는다 | conclude | 결론을 내린다, 결론이다 |
| 짚어 낸다 | pinpoint | 특정한다, 지적한다 |
| 다시 쓴다 | reuse | 재사용한다 |
| 돌려준다 | return | 반환한다 |
| 닿다 | reach | 거치다, 실행하다 |
| 버리다, 쳐내다 | prune | 제거한다, 가지치기(용어 'pruning' 병기) |
| 앞세운다 | lead with | 우선 제시한다 |
| 동반 연구 | companion work | 선행 연구 |
| 운영 준비가 된 | production-ready | 실제 운영에 적용할 수 있는 |
| 가장 진단적인 | most diagnostic | 결함 위치를 가장 정확히 알려 주는 |
| 책임을 묻는다 | attribute | 결함을 귀속한다 |
| 사람이 걷고 눈으로 판정 | walk through and inspect | 사람이 직접 조작하고 시각으로 확인 |
| 선택자 | selector | 요소 식별자(selector) |
| 행태 | behavior (양상) | 행동, 행위, 동작 중 뜻에 맞는 것 (행태는 부정적 함의) |

비유어 정리:
- 트리 비유 '뿌리·잎·가지치기'는 학술 용어가 아니다. 루트 노드, 단말 노드, 경로 제거(pruning, 첫 언급에 병기)로 쓴다.
- 구어(~거든요, ~하는 거다, ~하는 겁니다)는 본문에서 쓰지 않는다.

## 3. 용어 표기

- 첫 등장: 한글 설명 + 영문 병기. 예: "설계 단위(design unit)". 이후에는 약어나 한글 중 하나로 일관되게 쓴다.
- 핵심 용어는 첫 등장에 작은따옴표로 강조할 수 있다: '설계 단위'.
- 영어 용어(TAAU, DU, Playwright 등)는 영어 그대로 둔다.
- 한글 용어가 확정되면 용어표에 등재하고 문서 전체에서 같은 말을 쓴다. 용어 절차는 `terminology.md` 참조.

## 4. 문장 스타일

- 평서형으로 쓴다. 본문에 질문을 두지 않는다. 수사 질문은 쓰지 않는다. 질문이 필요하면 "~을 검토한다"로 평서문화한다.
- 본 연구는, 본 논문은, 본 절에서는 같은 주어 표현은 쓸 수 있다. 다만 "본 연구의 위치"는 제목으로 쓰지 않는다.
- 한 문장에 한 주장을 두는 것을 기본으로 한다. 조건절이 길면 두 문장으로 나눈다. (저자 판단으로 정한 규칙이다. 원천 영문은 접속사로 여러 절을 잇는 긴 문장이 많다.)
- 같은 대상을 가리키는 말을 바꾸지 않는다(동의어 변주 금지). 용어가 흔들리면 심사자는 다른 대상으로 읽는다.

## 5. 정의와 예시의 국문 표기

- `1) 정의:` `2) 예시:` `3) 논의:` `4) 적용:` (소절 제목 아래)
- 정의 번호 체계와 Algorithm 번호는 쓰지 않는다.

## 6. 인용 표기

- 번호를 주어로 쓰지 않는다. "[23]은" → "Qi 등[23]은", "선행 연구[3]는".
- 여러 번호는 연속 대괄호로 쓴다: [1][2][3]. 쉼표 [1,2,3]은 쓰지 않는다.
- 자기 계보는 방법론 접점마다 인용한다: "Kim [1][2]의 방법은 ...".
- 자세한 규칙은 `numbers-and-citations.md` 참조.

## 7. 캡션과 표 제목

- 그림 캡션: 제목만 쓴다. 설명은 본문 문장으로 옮긴다. 예: "그림 3. 행위 단위의 계층 구조."
- 표 캡션: 표 위에 쓴다. 예: "표 2. 단위 정의표."
- 그림 캡션은 아래, 표 캡션은 위에 둔다(교수님 연구실 관례).
- 과거 양식에서 캡션에 설명을 길게 쓴 경우가 있다. 최신 기준은 제목만이다.

## 8. 수치 문장

- 수치 뒤에는 기준선을 함께 쓴다: "0.772 대 무작위 0.500" 또는 "무작위 순서(0.500)보다 높은 0.772".
- 차이는 퍼센트포인트(pp)로 쓴다: "30.8 pp 높다".
- 일관성 지표는 임계와 함께 쓴다: "일관성비율 CR은 0.10 이하다".
- 자세한 규칙은 `numbers-and-citations.md` 참조.

## 9. 학회 양식 관련

국문 학회지와 논문지는 양식이 다르다. 학회지는 목차와 1단 구성을 쓰는 경우가 많고, 논문지는 2단 구성에 영문 초록을 앞에 두는 경우가 있다. 양식 세부는 게재지 규정을 따른다. 본문 문체 규칙은 양식과 무관하게 같다.

## 10. 국문 작성 체크리스트

- [ ] 대체표의 번역체 표현이 없는가 (`scripts/style_lint.py`로 검사)
- [ ] 본문에 질문형 문장과 구어가 없는가
- [ ] 트리 비유어가 학술 용어로 바뀌었는가
- [ ] 용어가 첫 등장에 영문 병기되었는가, 이후 흔들리지 않는가
- [ ] 인용 주어가 저자명 + 번호 형식인가
- [ ] 캡션이 제목만인가
- [ ] 수치에 기준선이 있는가
