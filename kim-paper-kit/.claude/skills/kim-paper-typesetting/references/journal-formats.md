# 저널 양식 실측 (TIIS · TKIPS · 학회지 · IJIBC)

양식은 **공식 파일과 게재본 PDF 실측**으로만 정한다. 가이드 문서의 치수나 교수님 샘플과 게재본이 어긋나면, 게재본을 기준으로 두고 지도 교수께 확인한다.

---

## 0. 먼저 확인할 것

1. **간행물 종류를 확정한다.** 같은 학회라도 학회지(회원 대상 기고, 1단, 목차)와 논문지(심사 논문, 2단, 영문 초록 선두)는 양식이 다르다. 실제로 조판을 시작한 뒤에 바꾸면 전면 재작업이 된다. 투고 대상이 무엇인지 먼저 적어 둔다.
2. **공식 템플릿과 게재본을 받는다.** 게재본 PDF 를 최소 한 편(가능하면 9편 안팎) 구해 색, 첫 쪽 구조, 머리글, 쪽수 범위를 실측한다.
3. **가이드 치수와 제출 치수를 구분한다.** 가이드의 페이지 크기가 재단 치수(트림)라면 공식 템플릿(예: A4)을 그대로 쓴다. 페이지 크기를 임의로 바꾸지 않는다.
4. **필요한 글꼴을 설치 확인한다.** 양식 글꼴이 없으면 대체 글꼴로 조판되어 양식이 틀어진다 (`environment.md`).

---

## 1. TIIS (영문 저널, 투고 시 Word 템플릿 사용)

공개 게재본 9편 실측 (2026-08).

- **쪽수**: 13~21쪽. **A4** (21.0 × 29.7cm). 게재 PDF 도 A4 다. 공식 Word 템플릿의 페이지 설정을 그대로 쓴다.
- **첫 쪽 표제 글꼴**: "Abstract" 와 "Keywords:" 라벨은 Arial 굵은 기울임 12pt (게재본 실측, 원천 조판기 설정).
- **스타일 이름 (원천 조판기가 쓴 템플릿 스타일)**: `제목1`, `Author`, `Affiliation`, `Abstract title`, `Abstract Keywords Text`, `heading1`, `heading2`, `body`, `References`, `table title`, `fig,table text`. 템플릿마다 이름이 다르므로 키트의 예시 이름은 자기 템플릿에 맞춰 바꾼다.
- **색 규정 (게재본 실측)**
  - 본문 인용 `[N]`, `[N–M]`: **빨강**, 11pt, 굵지 않음.
  - 본문 `Fig.`/`Table` 참조: **파랑 + 굵게**.
  - 캡션 접두 `Fig. N.`: 파랑 + 굵게, 10pt. 캡션 설명은 검정.
  - 섹션 헤딩: **보라(#9900ff)**, 12pt, Arial 굵게.
- **첫 쪽 구조**
  - Copyright 줄(`© YYYY KSII`)은 **머리글 2행**에 있다 (바닥글이 아니다).
  - 사사(funding) 문단은 첫 쪽 **바닥글**에 둔다.
  - 사사 아래에 DOI 와 ISSN 을 적는 자리표시 줄이 있다. 템플릿 바닥글을 통째로 바꾸면 이 줄이 유실된다 (실제 사고). 보호할 줄을 골라 다시 넣는다.
- **교신저자 표기**: 저자 줄 끝에 `*`, 그 아래 `[e-mail: …]` 줄, 그다음 `*Corresponding author: 이름` 줄. 게재본은 교신저자 줄에 이메일을 붙이지 않는다.
- **머리글**
  - 홀수 쪽: 저널명과 `VOL. X, NO. X`. 템플릿에 남은 다른 권호 표기(예: "VOL. 3, NO. 6")는 `VOL. X, NO. X` 로 통일한다.
  - 짝수 쪽: 쪽 번호(왼쪽) + `제1저자 et al.: 축약 제목`(오른쪽), 8pt. 쪽 번호는 PAGE 필드로 둔다.
- **필수 요소**
  - 저자 약력: **전원분**. 없으면 반려된다.
  - 초록 150~250단어, 키워드 5~6개.
  - 인용은 본문 첫 등장 순서.
  - 참고문헌: 게재본 실측 **25~79개** (중앙값 약 44). 20개 이하는 하한 미달로 지적받을 위험이 있다.
- **리비전 제출**: 수정 표시와 답변서 구성은 `revision-and-response.md`.

## 2. TKIPS (정보처리학회 논문지, 2단)

공식 양식 파일과 발간본 1권(제15권 제8호) 실측.

- **쪽 규격**: A4 (595.3 × 841.9pt). 발간본 PDF 는 A4 에 재단 여유 3mm 를 더한 크기다.
  - 좌우 여백 55.2pt, 상단 본문 시작 100pt, 하단 여백 76pt, 머리말 거리 64pt.
  - 본문 폭 485pt. 단 폭 232.5pt, 단 간격 20pt.
- **본문 줄**: 본문 9pt, 줄 간격 **정확히 14.2pt**.
- **순서**
  1. 영문 제목, 영문 저자, ABSTRACT(300단어 이하), Keywords (1단)
  2. 국문 제목, 국문 저자, 요약, 키워드 (1단)
  3. 본문 (2단)
- **글꼴 (실측 크기)**
  | 요소 | 글꼴 | 크기 |
  |------|------|------|
  | 머리말 | 세고딕 | 7.5pt |
  | 영문 제목 | 견명조 | 14pt |
  | 영문 저자 | 중고딕 | 10pt |
  | ABSTRACT 제목 | 태고딕 | 10.5pt |
  | 초록 본문 | 신명조 | 7.5pt |
  | Keywords | 태고딕 | 7.5pt |
  | 국문 제목 | 태명조 | 19pt |
  | 국문 저자 | 중고딕 | 10pt |
  | 장 제목 | 견고딕 | 10pt |
  | 절 제목 | 중고딕 | 9pt |
  | 본문 | 신명조 | 9pt (줄 14.2pt) |
  | 그림·표 제목 | 중고딕 | 8.5pt |
  | 표 본문 | 신명조 | 8pt |
  | 첫 쪽 각주 | 신명조 | 7pt |
  | References | 견고딕 | 10pt (양식 문서 기재값. 조판기 구현은 신명조 8.5pt 이므로 확인 필요) |
  | 약력 | 이름 중고딕 11pt, 본문 신명조 8.5pt | |
- **글꼴 대응 (설치된 한글 글꼴)**: 견명조·태명조 → HY견명조, 신명조 → HY신명조, 중고딕·세고딕 → HY중고딕, 견고딕·태고딕 → HY견고딕. 라틴 문자는 Times New Roman. 고딕 문맥의 라틴 글자는 **Arial** 을 쓴다 (HY중고딕의 라틴 하이픈이 긴 빼기표처럼 보인다).
- **장절 번호**: `1.` → `1.1` → `1)` → `a)` 4단계. `3.1.1` 같은 3단 번호는 쓰지 않는다.
- **그림·표 제목은 영문**: 그림은 아래 `Fig. 1.`, 표는 위 `Table 1.`. 본문 인용은 `[1, 2]`, `[1-3]`. 그림 참조는 `Fig. n`.
- **줄 끝 낱말 끊기**: 발간본은 줄 끝에서 한글 낱말을 끊는다(예: "패/키지"). 그래서 2단 본문은 WordWrap=False 를 쓴다. 제목은 WordWrap=True 로 두고 낱말 경계에서 두 줄의 길이를 비슷하게 나눈다 (`word-com-rules.md` §4).
- **표 조판 (원천 실측 설정)**: 표 셀 글꼴 신명조 8pt, 줄 간격 정확히 10.5pt, 위아래 여백 0.5pt, 좌우 여백 3pt. 테두리는 안쪽 0.25pt, 바깥 0.75pt.
- **자동 하이픈**: 원천 조판기는 `AutoHyphenation = False` 로 두었다.
- **첫 쪽 각주 상자**: 왼쪽 단 하단에 7pt 로 둔다. 내용은 과제 사사, 회원 등급, 소속, 접수·수정·채택일, 교신저자. 본문 위에 고정된 텍스트 상자로 만든다.
- **약력**: 사진 + 이름 + 항목. 사진은 3:4 비율로 자른다. 가로로 넓으면 가운데를, 세로로 길면 위쪽을 기준으로 자른다.
- **환경 조건**: 한컴 뷰어만 설치된 PC 에서는 HWP OLE 조판을 쓸 수 없다. 정식 한글이 필요하다 (`environment.md`).

## 3. 학회지 (정보처리학회지 기고, 1단)

집필 안내와 발간본 1권 대조로 확정했다 (2026-10-01).

- **1단**. 바탕 10pt, 줄 간격 160%. 목차 블록이 있다.
- **캡션은 한글**: 표는 `<표 1>`, 그림은 `(그림 1)`.
- **초록과 영문 제목 없음**: 구성은 제목 → 성명 → 목차 → 본문 → 참고문헌.
- **장 제목**: "1. 서 론", "결 론" (글자 사이를 띄운다).
- **서론은 소절 없이 한 흐름**: 교수님은 서론을 1.1, 1.2 로 나누는 것을 싫어하셨다. 조판 전에 원고 구조를 맞춘다.
- **약력**: 이름 줄 + "연도 학교 학과(학위)" 한 줄씩 + 관심분야 + 이메일. 약력 분량은 집필 안내상 200자 이내로 기록되어 있다 (원문 재확인 필요). 사진은 게재가 확정된 뒤 넣는다.
- **참고문헌**: 규정은 저자명 사전식이고 발간본은 인용 순서다. 어긋나면 발간본과 지도 교수께 함께 확인한다.
- 학회지 양식과 논문지 양식은 **같은 조판기로 처리하지 않는다.** 논문지 투고가 정해지면 2단 논문지 조판기를 새로 만든다.

## 4. IJIBC (영문 저널, Word 양식 기반)

- 저널 양식 파일(교수님 제출본 양식)을 base 로 새 판을 만든다. 기존 판을 덮어쓰지 않는다.
- **그림 캡션**: `Figure N. 설명.` (마침표 필수). 본문 인용은 `[N]`.
- 참고문헌은 DOI 를 확인한 뒤 추가한다. 인용 형식 생성 도구가 있으면 DOI 검증 후 생성한다.
- 그림의 폰트·팔레트 규격은 키트의 그림 영역 문서를 따른다. 조판 문서에서는 캡션과 배치만 다룬다.

## 5. 공통 교훈 (여러 저널에서 확인)

- **가이드 치수 ≠ 제출 치수**: 가이드의 크기가 재단 기준이면 공식 템플릿을 그대로 쓴다.
- **템플릿의 보호 줄**: 첫 쪽 바닥글의 DOI·ISSN 줄, 머리글의 권호 표기는 통째로 바꾸면 사라진다. 바꾸기 전에 보존한다.
- **게재본 실측이 최종 기준**: 색, 글꼴 크기, 첫 쪽 구조는 게재본 PDF 를 `pdf_page_audit.py --spans` 로 재서 대조한다.
- **참고문헌 개수**: 저널 게재본의 분포로 하한을 확인한다 (TIIS 예: 25~79개).
- **교수님 샘플 ≠ 게재본**: 샘플과 게재본이 다르면 게재본을 기준으로 하고, 어긋난 점을 지도 교수께 확인한다.
