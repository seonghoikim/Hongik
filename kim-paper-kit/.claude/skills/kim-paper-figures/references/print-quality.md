# 인쇄 품질 — 픽셀 폭과 실효 글자 크기

그림이 인쇄에서 읽히는지는 두 값으로 판정한다. 파일의 DPI 메타데이터는 판정에 쓰지 않는다.

## 1. 판정 기준 두 개

**기준 A — 픽셀 폭 (실효 dpi)**

```
필요 픽셀 폭 = 인쇄 폭(pt) / 72 × 300   (올림해서 정수 px로 쓴다)
```

- 인쇄 폭 368pt → 1533.3px → **1534px**. 인쇄 폭 485pt → 2020.8px → 2021px. 인쇄 폭 232.5pt → 968.75px → 969px.
- **1533px는 299.9dpi라서 미달이다.** 원천 기록의 "1533px"은 근사값이었다. 키트 스크립트(`check_figure_print.py`, `render_html_figure.py`)는 1534로 통일했다.
- **Why:** 학위논문 조립기는 모든 그림을 368pt 폭으로 강제 리사이즈한다. PNG에 "300dpi"를 써 넣어도 결과는 바뀌지 않는다. 실제로 결정되는 값은 픽셀 수다. 한 번의 전수 실측에서 그림 세 장이 176~190dpi로 미달했다.

**기준 B — 실효 글자 크기**

```
실효 글자(pt) = 글자 크기(px) / 캔버스 폭(px) × 인쇄 폭(pt)
```

- 목표: 가장 작은 글자가 **8pt 이상**. 중앙값으로 판정하지 않는다. 각주나 범례 한 줄이 4pt여도 평균은 통과할 수 있다.
- 단위는 비율로 계산되므로 px와 pt를 섞어도 된다. 글자와 캔버스를 같은 단위로만 잰다.

## 2. 인쇄 폭 (프로젝트 측정치)

| 레이아웃 | 인쇄 폭 | 비고 |
|----------|---------|------|
| 학위논문 조립기 (그림 강제 폭) | 368pt | 프로젝트 조립기 기준 |
| 2단 논문지의 본문 전폭 | 485pt | 한 쪽 본문 폭 측정치 |
| 2단 논문지의 단 하나 | 232.5pt | 단 폭 측정치 |
| 그 밖의 양식 | 게재지 템플릿에서 측정 | 추측하지 않는다 |

## 3. 설계 순서

1. **인쇄 폭 W를 정한다.** 본문 폭 100%가 기본이다 (§6).
2. **캔버스 폭 C(px)를 정한다.** 예: 1700px.
3. **최소 글자 F를 계산한다.** `F ≥ 8 × C / W`. 예: C = 1700, W = 368이면 F ≥ 37px.
4. **렌더 배율 s를 정한다.** PNG 폭 = C × s ≥ 기준 A. 예: s = 3이면 5100px.
5. **검사한다.**
   ```
   python <KIT>/scripts/check_figure_print.py --png figures_png/fig.png --print-width-pt 368
   python <KIT>/scripts/check_figure_print.py --font-px 37 --canvas-px 1700 --print-width-pt 368
   ```

## 4. 기존 수치 재검토 (옛 기록을 그대로 믿지 말 것)

프로젝트 기록에 있던 값을 공식으로 다시 계산한 결과다. 옛 기록을 근거로 새 그림의 글자 크기를 정하지 않는다.

| 기록 | 공식 재계산 (W = 368pt) | 판정 |
|------|------------------------|------|
| 1700px 캔버스, 글자 19~26px이면 "인쇄 6~8pt" | 19px → 4.1pt, 26px → 5.6pt | 8pt 미달. 기록과 맞지 않음 |
| 캔버스 872pt, 글자 19pt → "실효 8.5pt" | 19 × 368 / 872 = 8.0pt | 기록보다 작음 |
| 캔버스 1050pt, 글자 13pt → "실효 4.6pt" | 13 × 368 / 1050 = 4.6pt | 일치, 판독 불가 수준 |
| 발표 캔버스 1340px, "최소 26px" | 1340 / 58 ≈ 23.1px | 계산식과 맞지 않음 |

- 기록 차이의 원인은 대부분 **인쇄 폭 가정**이다. 같은 캔버스라도 W가 다르면 결과가 다르다. 새 그림은 W를 먼저 정하고 공식으로 다시 계산한다.
- **Why:** 옛 기록을 믿고 글자를 19~26px로 두면 실제 인쇄에서 4~6pt가 되어 읽히지 않는다.

## 5. 글자가 작을 때 할 일

- **해상도를 올려도 글자는 커지지 않는다.** 실효 글자는 캔버스와 인쇄 폭의 비율로 정해진다.
- **캔버스를 좁힌다.** 라벨을 짧게 끊고, 긴 주석 상자는 그림에서 빼서 캡션이나 본문으로 옮긴다.
  - 프로젝트 사례: 캔버스를 1050pt에서 872pt로 줄이고 글자를 19pt로 키워 실효 글자를 4.6pt에서 8pt대로 올렸다 (기록 8.5pt, 공식 8.0pt).
- 도식을 둘로 나눈다. 조밀한 표(프로젝트 예: 9행 × 16열 행동 매트릭스)는 2장으로, 긴 시퀀스 다이어그램은 구간별 2~3장으로 나눈다.

## 6. 고정좌표 도식과 자동 레이아웃

- **CSS flex/grid 기반 도식**은 글자 배율을 키워도 대부분 맞는다.
- **SVG 절대좌표 도식**은 글자만 키우면 라벨이 노드와 겹치고 캔버스 밖으로 잘린다. 글자, 좌표, 간격, 캔버스를 함께 재배치한다.
- 글자만 키우면 그림이 세로로 길어져 쪽이나 슬라이드 높이를 넘는다. 내용을 줄이거나 분할한다. (슬라이드 기준으로는 가로/세로 2.3 이상을 유지한다, §9)
- **Why:** 같은 그림이 "글자는 커졌는데 가독성은 그대로"인 상태가 된다. 재배치 없이 배율만 키우면 반드시 깨진다.

## 7. 흑백 인쇄 확인

- `check_figure_print.py --png <file> --gray-out <file_gray.png>`로 회색 미리보기를 만든다.
- 빨강은 흑백에서 중간 회색이 된다. 그래서 강조 요소는 색만이 아니라 **선 굵기나 테두리로도** 구분되는지 본다.
- 회색 단계 두 개가 흑백에서 구분되는지 확인한다.

## 8. 본문 폭 100%

- 그림은 좌우를 본문 폭에 꽉 채우는 것이 기본이다.
- **Why:** 쪽수를 맞추려고 그림 폭을 62~92%로 줄였더니 그림 속 글자가 인쇄에서 읽히지 않는다는 지적을 받았다. 교수님은 그림만으로 논문을 읽으시므로, 그림의 가독성이 본문보다 우선이다.
- **How:** 쪽수가 넘치면 **본문 문장을 줄인다.** 그림을 줄이지 않는다. 큰 그림이 쪽 끝에 안 들어가 빈칸이 생기면 `word-insertion.md`의 지연 삽입을 쓴다.

## 9. 발표용 그림 (슬라이드)

논문용 그림을 그대로 슬라이드에 넣으면 읽을 수 없다. 발표용은 **별도 소스**로 만든다 (예: `*_pptsrc.html` → `*_ppt.png`). 논문 원본은 손대지 않는다.

**실효 pt 계산 (같은 공식, 인쇄 폭만 슬라이드 표시 폭으로 바꾼다)**

```
실효 pt = 최소 글자 px / 캔버스 CSS 폭 × 슬라이드 표시 폭(pt)
슬라이드 표시 폭 = min(약 899pt, 그림 영역 높이(pt) × 종횡비)
```

- 함정 1, 렌더 배율: PNG 픽셀 폭은 캔버스 CSS 폭이 아니다. `device scale` 배율로 나눈 뒤 계산한다. 프로젝트에서는 배율이 2배인 스크립트와 2.5배인 스크립트가 섞여 있었는데, 배율을 빼고 계산해 도식 아홉 장을 "미달"로 잘못 판정한 적이 있다.
- 함정 2, 높이 제한: 종횡비가 낮은 그림은 폭 전체를 쓰지 못한다. 그림 영역 높이를 먼저 계산한다.
- 함정 3, 최소값: 판정은 최소 글자로 한다.

**실무 기준 (프로젝트 기록, 슬라이드 레이아웃 기준)**

- 슬라이드 표시 폭 899pt(12.49in)는 프로젝트 템플릿의 그림 전체 폭이다. 다른 템플릿이면 실제 폭을 다시 잰다.
- 그림 영역 높이(프로젝트 측정): 이미지형 약 338pt, 도식형 약 389pt. 종횡비 2.0인 그림은 폭 전체를 쓰지 못하고 약 10.4in로 줄어 실효 pt가 17% 깎인다.
- **최소 글자 px ≥ 캔버스 CSS 폭 / 58.** 899pt 폭에서 이 기준은 실효 약 15.5pt에 해당한다. 같은 프로젝트의 다른 스크립트 주석은 14pt(비율 1/64)였다. 새 그림은 목표 실효 pt를 먼저 정하고 비율을 계산한다: 비율 = 목표 pt / 슬라이드 폭 pt.
- 가로 / 세로 ≥ 2.3
- 설명 상자 글자는 11pt 이상. 여백이 남는 불릿 슬라이드는 글자를 키우되 최대 18pt까지다 (빈 상자보다 큰 글자가 낫다).
- 고정좌표 도식은 배율만 키우지 말고 재배치한다. 세로 스택 레이아웃은 가로 배치로 바꾼다.

**검증:** `check_figure_print.py --font-px <글자> --canvas-px <캔버스> --print-width-pt <슬라이드 표시 폭>`으로 수치를 확인하고, 내보낸 슬라이드 PNG를 눈으로 본다. 수치는 통과하는데 겹쳐서 읽히지 않는 경우가 있었다.
