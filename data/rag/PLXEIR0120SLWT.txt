[03 조작방법]
* 조작부 구성: 잠금(3초), 내림(v), 올림(^), 파워/온도/시간 표시 LED창, 모드 설정, 전원 버튼

- 전원: 전원코드 연결 후 '삐-'소리 1회, LED 표시창에 'OFF'가 표시됩니다. 전원 버튼을 1번 터치하면 LED 표시창에 'ON'이 표시됩니다.
* 전원 끄기 : 작동 모드나 준비 모드일 경우, 전원 버튼을 터치하면 LED 표시창에 'OFF'표시와 동시에 제품이 동작을 멈춥니다.

- 모드 설정
1. 파워 모드: 모드 설정 버튼을 터치하면 설정 가능합니다. 200W에서 최대 2000W까지 설정 가능합니다. (기준 W: 200, 400, 600, 800, 1000, 1200, 1400, 1600, 1800, 2000)
2. 온도 모드: 모드 설정 버튼을 터치하면 설정 가능합니다. 60°C 에서 최대 220°C 까지 설정 가능합니다. (기준 °C: 60, 80, 100, 120, 140, 160, 180, 200, 220)

- 시간 설정
파워, 온도 모드의 동작 중 모드 설정 버튼을 터치하면 시간을 설정 가능합니다. 시간 설정 최초 표시는 '0:30'입니다. [v], [^] 버튼을 터치하여 시간을 설정할 수 있습니다. (0~3시간 설정 가능)

- 어린이 보호 기능
1. 어린이 보호기능 동작: 잠금 버튼을 3초간 터치하면 LED 표시창에 'Loc'이 표시되며 어린이 보호 기능이 활성화됩니다. 이때 어린이 보호 기능 버튼과 전원 버튼 외 다른 버튼은 작동되지 않습니다.
2. 어린이 보호기능 해제: 어린이 보호 기능에서 다시 잠금 버튼을 3초가 터치하면 해제됩니다.

[04 청소방법]
아래 사항들을 숙지하시고, 항상 청결한 상태를 유지하며 제품을 사용해 주십시오.
- 제품의 전원코드를 뺀 후 제품의 열이 완전히 식을 때까지 기다리십시오.
- 제품 사용 후 청소하십시오.
- 냄비, 팬을 닦지 않고 사용할 경우 제품이 변색될 수 있습니다.
- 벤진, 희석제, 솔, 윤택제를 사용하여 세척하지 마십시오.
- 세제를 사용하여 젖은 천으로 닦아 주십시오.
- 제품 안에 물이 있는 상태에서 작동시키지 마십시오. * 물이 있을 경우 고장의 원인이 됩니다.
- 제품 본체를 물로 세척하지 마십시오. * 본 제품은 전기제품이므로 전기부품에 물이 들어갈 경우 고장 및 화재의 원인이 됩니다.

[05 조치사항 (에러코드)]
A/S를 요청하기 전에 아래의 사항을 확인해 주십시오. 
- 'E0' 표시: 용기 없음, 용기 작음, 용기 옮김 -> 적당한 사이즈의 냄비를 다시 인덕션 위에 올려 주십시오.
- 'E2' 표시: 감지센서 합선의 경우 -> 서비스 센터로 문의하십시오.
- 'E3' 표시: 전압이 270V 이상일 경우 -> 제품의 전압과 알맞은 전기 콘센트에 제품을 연결 사용하십시오.
- 'E4' 표시: 전압이 150V 이하일 경우 -> 제품의 전압과 알맞은 전기 콘센트에 제품을 연결 사용하십시오.
- 'E5' 또는 'E6' 표시: IGBT(전력용 반도체) 과열 -> 제품을 식힌 후, 완전히 껐다 다시 켭니다.
* 수리 기술자 이외의 사람은 분해 및 수리하지 마십시오. 화상, 감전, 상해의 원인이 됩니다. 고장이나 기타 증상 발현시 구입하신 판매점이나 고객서비스 센터와 상의하여 주십시오.
