# RAG 원본 자료 (raw)

이 폴더는 Unit B(RAG)에 구조화해 넣을 **원본 소스 자료**를 보관하는 곳입니다.
`data/rag/kb_v*.json`(실행 시점 스냅샷, 코드가 자동 생성)과는 다릅니다 — 이
폴더는 사람이 수집한 원본을, `src/hongik_selfheal/knowledge_base.py`가 실제로
쓰는 `KBEntry(keywords, content)` 형태로 가공하기 전 단계의 자료를 보관합니다.

## 여기 넣을 것

- 실제 인터넷 쇼핑몰 등에서 받은 **공개 제품 설명/카탈로그 자료** (텍스트, 캡처,
  PDF 발췌 등 형식 무관)
- 실제 사용 중인 **시스템 프롬프트 원문** (별도 파일로 저장 권장: `system_prompt.txt`)

## 여기 넣지 말 것

- 실제 회원(고객) 개인정보 — 이 프로젝트의 회원정보는 전부
  `src/hongik_selfheal/fake_members.py`의 가공 데이터를 사용합니다. 실제
  고객 데이터는 절대 넣지 마십시오.
- 비공개/기밀 자료. 이 폴더에 넣는 자료는 공개 출처여야 합니다(2026-08-04
  연구자 확인: 여기 들어갈 제품 자료는 인터넷 쇼핑몰에서 다운받은 공개 자료).

## 반영 절차

1. 원본 자료를 이 폴더에 추가
2. `knowledge_base.py`의 `DEFAULT_KB`에 키워드 매칭 항목으로 옮겨 담음
3. `KB_VERSION`을 올리고(`kb_v2`, `kb_v3`, ...) 실행 시 `data/rag/{KB_VERSION}.json`
   으로 자동 스냅샷 저장됨
