기억의흐름및저장
6
데이터는어떻게'기억'이되는가?
1.
입력(Input)
입력전처리(욕설제거, 감정분석) 수행→ 의도, 톤결정.
대화컨텍스트는'단기기억'에임시보관됨.
2.
승격(Promotion)
'전이규칙'에따라'장기기억'으로승격됨.
전이규칙: 감정강도, 주제반복등
3.
저장(Storage)
각기억항목은요약문, 키워드, 타임스탬프를포함, 임베딩을생성하여
Vector DB에저장됨.
오래된항목은요약및페이딩(Fading) 처리.

기억추론아키텍처
7
기억계층(Memory Layer)과능동형RAG 추론계층(Inference Layer)으로구성
1.
Memory Layer (좌측) : 기억의흐름(Short-term → Episodic → Prospective 
→ Semantic )'의미기억(Semantic)'은RAG 파이프라인(RAG Feature Pipeline) 
을통해인터넷데이터(Internet/web-Data) 로최신화
2.
Inference Layer (우측) : State Client 가사용자의상태(의도/정서/맥락)를
고려.Retriever Tool 이'의미기억'에서관련정보선별.선별된정보를
Procedure Memory 에담아사용자에게'능동적으로언급' (이것이기억
미러링의구현)

기억추론및출력
8
정보가어떻게검색되고답변으로생성되는가?
1.
검색(Retrieve) : 사용자입력이들어오면Vector DB에서근접후보(유사기억)를회수(Retrieve)
기억미러링의재료로서일화/의미/미래기억의키워드검색으로수집
2.
주입(Inject) : 회수된기억을Prompt Management 를통해프롬프트에주입
단기기억과함께검색하여수집된기억들, 타임스탬프를포함하여프롬프트에주입
3.
생성(Generate) : LLM Gateway 및LLM API 를통해Large Language Models 가답변생성
4.
조절(Control) : 최종출력단계에서톤(Tone)과길이를조절
의인화요소를토대로아바타의캐릭터성을부각하여답변의뉘앙스를다듬어출력

결론
10
1.
연구요약및기여
본연구는아바타의의인화를위해'기억중심설계'를제안
이를구현하기위해'단기-장기2계층기억구조'와사용자의상태를고려하는'능동형RAG 추론아키텍처'를설계
제안하는구조는아바타가사용자의맥락을인지하여선별된기억(정보)을능동적으로언급('기억미러링') 할수있게함.
2.
주요성과
제안아키텍처를통해아바타가인간의기억작동방식과유사한상호작용을수행함을사례로보임.
- 의미기억: 초기대화정보(MBTI, 직업등) 회상
- 일화기억: 개인적추억및특정이벤트회고
- 절차기억: 사용자와의상호작용(요구)을통해'퇴근규칙' 같은행동규칙이학습되고변화함
3.
향후연구
장기기억으로승격시키는트리거(Trigger) 기준의정교화필요.
기억의요약및페이딩(Fading) 과정에서발생하는정보손실을최소화하기위한방안모색.
